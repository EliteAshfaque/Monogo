# Monogo

Backend learning projects: Basic, authentication, medium, and Spotify/Sonora MVP.

## Sonora music MVP

Use two terminals from the `spotify` folder (or root scripts if configured):

```bash
npm run server
```

```bash
npm run client
```

Open the URL shown by Vite (usually `http://localhost:5173`).

To load the sample catalog and admin account once:

```bash
npm run seed
```

See project folders: `Basic/`, `authentication/`, `medium/`, `spotify/`.
